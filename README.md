### En qué trabajo ahora
 
**PsyTrack**. Aplicación Android con la que una consulta de psicología gestiona las fichas de sus pacientes, organiza la agenda y registra cada sesión. Los datos de cada clínica quedan aislados en las reglas de seguridad de Firestore. Kotlin, Jetpack Compose, MVVM, Firestore. Repositorio privado.
 
**Integración con el SEPE**. Plugin de Moodle que publica el servicio SOAP de seguimiento de teleformación que el organismo exige a los centros acreditados. Escrito sobre el WSDL oficial, con autenticación WS-Security. PHP. Repositorio privado.
 
**API de análisis postural**. API REST para una aplicación móvil, en producción. Las imágenes se cifran con AES-256-GCM antes de guardarse y el servicio corre en Docker detrás de Nginx. Node.js, TypeScript, Firebase Auth. Proyecto de cliente.
